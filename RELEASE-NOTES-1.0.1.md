# DeadNET 1.0.1 — Visual Refresh and Mobile PWA

- Replaced the original mark with a minimal mountain-and-sun identity.
- Refreshed the interface to a charcoal / red visual theme.
- Added 192px and 512px install icons and Apple touch icon metadata.
- Updated PWA manifest and service-worker core cache for mobile installation.
- Added Android Chrome and iOS Safari home-screen installation guide.

## Distribution note
This source release supports PWA installation on Android and iOS when hosted over HTTPS. It does not include signed APK/IPA binaries or app-store publication. Native signing/build steps require the respective platform toolchains.
